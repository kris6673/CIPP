# Add Template

This page creates a new GDAP role template. A template groups together the role mappings you have already created on the roles page, so that the same set of permissions can be applied consistently to every invite and onboarding.

| Field                     | Description                                                                                               |
| ------------------------- | --------------------------------------------------------------------------------------------------------- |
| Template Name             | The name for the template. This is the value shown when selecting a template elsewhere in CIPP. Required. |
| Select GDAP Role Mappings | The role mappings to include in the template. At least one mapping is required.                           |

{% hint style="info" %}
Role templates are used to create new GDAP invites for your customer tenants. Make sure to select a template that matches the permissions you want to grant.
{% endhint %}

{% hint style="info" %}
Only mappings that already exist on the [roles](../roles/ "mention") page can be selected. If a role you need is missing, create the mapping first and then return here.
{% endhint %}
