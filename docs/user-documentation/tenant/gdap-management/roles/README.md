# Role Mappings

Role mappings have moved. The list of role-to-group mappings now lives under Role Templates as [Group Mappings](../role-templates/mappings.md), and new mappings are created for you when you build or edit a [role template](../role-templates/README.md). Mapping a pre-existing group by hand is still available as [Map an existing group (Advanced)](add.md).
