# Edit Mapping

Change an existing mapping. The form is the same as [add.md](add.md "mention") and is pre-populated with the current configuration, so the same field descriptions apply.

{% hint style="warning" %}
Changing the destination attribute does not move or remove values already written under the previous attribute. Those values remain on the directory objects until you clear them yourself.
{% endhint %}

Saving a Reporting DB mapping re-registers the scheduled synchronisation tasks for the selected tenants.
