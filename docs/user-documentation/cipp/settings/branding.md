# Branding

Branding controls the logo, cover image and accent colour applied to PDF reports and documents generated by CIPP. Settings apply across the whole instance rather than per user, so any report generated by any technician uses the same branding.

The page is split in two. The left side holds the logo and cover image galleries, and the right side shows a live cover preview alongside the brand colour and the save controls.

## Logo

The logo gallery is a horizontal strip of tiles. Select a tile to make that logo active, or select the tile marked with a plus to upload a new one. The **No logo** tile leaves reports without a logo.

| Requirement      | Detail                                                                                                      |
| ---------------- | ----------------------------------------------------------------------------------------------------------- |
| Format           | PNG or SVG preferred. JPG and WebP are accepted.                                                            |
| Maximum size     | 2MB. Larger files are rejected before upload.                                                               |
| Ideal dimensions | Around 200x100px, or a similar aspect ratio.                                                                |
| Background       | A transparent background is recommended, since the logo appears over both the cover image and page headers. |

Uploaded logos can be removed with the delete icon in the corner of their tile. Stock tiles cannot be deleted.

## Cover Image

The cover image appears on report cover pages only, and is not used elsewhere in the document. The gallery holds an upload tile, a **No cover image** tile, any covers you have uploaded, and six stock images.

| Stock cover |
| ----------- |
| SOC         |
| Board       |
| Glasses     |
| Working     |
| Laptop      |
| City        |

SOC is the default for a new instance. Selecting **No cover image** produces a cover page with no background image.

| Requirement      | Detail                                                                                                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Format           | JPG or PNG.                                                                                                                                                                |
| Maximum size     | 2MB.                                                                                                                                                                       |
| Ideal dimensions | Around 1240x1754px, which is A4 portrait at roughly 150dpi, or a similar portrait aspect ratio.                                                                            |
| Subject matter   | Soft or dark imagery works best, because the image is displayed full bleed at around 50% opacity behind the cover text. Busy or bright images make the title hard to read. |

Uploaded covers can be removed with the delete icon on their tile.

## Brand Color

Sets the accent colour used for highlights throughout generated reports. The default is `#F77F00`. Selecting the swatch opens a colour picker, and the cover preview updates as you change it.

## Cover Preview

Renders a sample cover page using your current logo, cover image and brand colour, so you can judge the combination before saving.

**Report Type Preview** switches the sample between the report types CIPP produces, each of which uses a different title and subtitle layout.

| Report type        |
| ------------------ |
| Executive Report   |
| Report Builder     |
| Shadow AI Report   |
| BEC Remediation    |
| Sharing Report     |
| Permissions Report |

{% hint style="info" %}
The preview is a rendering of the cover only. Changing the report type here has no effect on the saved branding, it simply changes which sample layout you are looking at.
{% endhint %}

## Saving and Resetting

Uploading and deleting images take effect immediately, without needing to save. Your choice of which logo and cover are active, along with the brand colour, are only stored when you select **Save Branding**.

{% hint style="warning" %}
Leaving the page after uploading an image but before saving keeps the uploaded file in the gallery, but the selection reverts to whatever was last saved. Upload, select, then save.
{% endhint %}

**Reset** returns branding to its defaults, restoring the `#F77F00` brand colour and the SOC stock cover.

{% hint style="danger" %}
Reset permanently deletes every logo and cover image you have uploaded, not just the active selection. There is no confirmation prompt and the files cannot be recovered. Keep copies of any custom artwork outside CIPP.
{% endhint %}
