# Display Mode

The moon or sun icon in the menu bar switches CIPP between light and dark mode. The icon shows the mode you will switch to, so a moon means clicking will move you to dark mode and a sun means clicking will move you back to light.

## Available Display Modes

* Light mode
* Dark mode

Your choice applies immediately and is remembered on that device. Because it is stored locally rather than with your CIPP account, each browser and device keeps its own setting, so you can run dark mode on one machine and light on another.

{% hint style="info" %}
On narrow screens the icon is not shown in the menu bar. Use the **Light Mode** or **Dark Mode** entry in the account menu instead, reached from your avatar at the right of the menu bar.
{% endhint %}
