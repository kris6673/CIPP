## **Table Details**

The properties returned are for the Exchange Online PowerShell command `Get-TenantAllowBlockListItems`. For more information on the command please see the [Microsoft documentation](https://learn.microsoft.com/powershell/module/exchangepowershell/get-tenantallowblocklistitems).
